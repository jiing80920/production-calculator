# 生產完工計算機 / Production Completion Calculator

單一檔案 `index.html`，無需建置或伺服器。

## 部署到 GitHub Pages
1. 建立新 repository，上傳 `index.html`（可附 `README.md`）。
2. Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main` / `(root)`。
3. 約一分鐘後可於 `https://<帳號>.github.io/<repo名稱>/` 開啟。

注意：頁面透過 cdnjs 載入 React 18.3.1，需要網路連線。
